# Ninaru 3D

Identidad aplicada a Home, PLP, PDP y administrador a partir de la referencia suministrada por el propietario.

- Navy: #2E2E56, texto y superficies oscuras.
- Lilac: #6B5BD6, botones, selección y títulos secundarios.
- Cyan: #12C4D6, acentos de impresión 3D.
- Pink: #E6007E, acentos de maquillaje.
- Blanco como fondo principal; tintes suaves derivados para tarjetas.

Tipografía: Nunito (Google Fonts), alternativa redondeada. La referencia no identifica la fuente exacta. El wordmark conserva el arte original; no está recreado con texto.

Archivo original: public/brand/ninaru-brandboard.png. El logo horizontal y símbolo se muestran mediante encuadres CSS de esa imagen sin modificar el archivo. Para producción conviene sustituir por archivos independientes SVG/PNG oficiales si están disponibles.

Se migra el nombre provisional Estudio en datos locales a Ninaru 3D sin borrar productos o cambios. Nombre personalizado distinto se conserva.

Validación: build local-demo aprobado, Home móvil sin desbordamiento horizontal, logo y PDP revisados visualmente en navegador. Google sigue desconectado.
